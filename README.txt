4riders Scan - Stage 1

1. Unzip this folder.
2. Android Studio > Open > choose the Scan4riders folder. Wait for "Gradle sync" to finish (first time is slow).
3. Plug in the phone with USB debugging on. Pick it at the top (device dropdown).
4. Press the green Run button.
5. On the phone: tap "1. Allow floating bubble", switch it on, go back.
   Tap "2. Start Scan bubble", press Allow / Start now on the screen recording prompt.
6. Open the Grab Driver app on an order and tap the blue Scan bubble.
