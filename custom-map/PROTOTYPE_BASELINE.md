# 4Riders Design Prototype

This branch is isolated from production and starts from the current production branch head `a0cd01fd84e4b1f268367164314e30eb8db03df0`.

The prototype must use the real 4Riders Custom Map application and its existing MapLibre/PMTiles data, GPS, building, road inspection, search, coverage and route-planning behavior. Design experiments belong on this branch only. Do not replace the real map with a mock map or alter production/backend data during the design phase.
